# Granny… Git Your Hub!
*A non-coder's guide to GitHub, AI-assisted creation, and digital possibilities for educators.*

**[Visit the website](https://octc-instructional-design.github.io/granny-git-your-hub/)** (deployment pending)

**Status: Work in progress.** An OCTC instructional design learning laboratory and future professional development resource.

## Purpose
Build confidence using GitHub's browser interface, version control, collaboration, GitHub Pages and AI-assisted creation. Designed for educators, not aspiring software engineers.

## Learning approach
Quick checklists for familiar tasks, deep dives into underlying concepts, and independent challenges. AI can demonstrate and assist, but independent practice establishes competence.
